# flashstore

Хранит данные во flash micro:bit v2 — они переживают перезагрузку и выключение питания.
Новая прошивка по USB может их стереть.

- ключ: до 15 байт, значение: до 1024 байт, всего около 4 КБ
- `сохранить во flash` / `прочитать из flash` для текста и чисел
- `во flash есть`, `удалить из flash`, `очистить flash`
- `код последней операции flash`: 0 — успешно, отрицательное число — ошибка

Только micro:bit v2. Не используй вместе с расширением Data Logger без проверки,
что их страницы flash не пересекаются.
